# Premiere Pro 25 硬字幕移除

Windows CEP 面板：选中时间线片段后，批量导出 H.264 MP4 预览并调用火山 AI MediaKit 视频 OCR；你只需在示例预览上确认一次总体擦除区域，该归一化区域将用于本批全部片段。上传/OCR 与云端擦除/下载可设置 1–20 个并行任务，默认 2；确认一次整批费用后，完成的视频会在原序列中替换匹配画面，时间线原音轨保持不动。

## 兼容范围

- Windows 10/11、Premiere Pro 25.0–25.9、CEP 12。
- 只处理活动序列中选中的普通视频片段。
- 需要 Adobe Media Encoder 可用，并在设置中提供一个可读取的 `.epr` 导出预设。
- 需要你自己的火山引擎 AI MediaKit API Key 和网络连接。

## 安装

1. 运行 `tools/package-extension.ps1`，生成 `Premiere-Hard-Subtitle-Remover-0.1.0.zip`。
2. 解压到 `%APPDATA%\Adobe\CEP\extensions\com.codex.hardsubtitleremover`。
3. 正式签名发布后可直接使用。开发/未签名版本需要在 Windows 注册表中为 CEP 12 设置 `PlayerDebugMode` 字符串值 `1`，然后重新启动 Premiere。安装程序不会替你修改注册表。
4. Premiere 菜单选择 **窗口 → 扩展（旧版）→ 硬字幕移除**。

开发目录也可以直接复制到上述扩展目录。可在 Premiere “关于插件”菜单中确认面板已加载。

## 初次设置

1. 在 [火山引擎 AI MediaKit 控制台](https://console.volcengine.com/mediakit) 创建 API Key。该 Key 按 `Authorization: Bearer <API Key>` 发给 AI MediaKit。
2. 在面板保存 Key。插件使用当前 Windows 用户的 DPAPI 加密，文件位于 `%APPDATA%\Codex\HardSubtitleRemover\api-key.dpapi`；明文不会放入扩展目录、Premiere 项目或日志。
3. 设置处理结果目录。
4. 默认使用 Adobe Media Encoder 的 H.264 MP4 高码率预设，保证扩展预览播放器能够显示画面；也可填写其他可用 `.epr` 路径。临时导出保留源尺寸、帧率和序列音频混音。

## 使用

1. 在 Premiere 活动序列中选中一个或多个普通视频片段，确保源媒体在线。
2. 打开面板并扫描选中片段；与其他视频重叠或包含转场的区间会跳过，以避免临时隔离导出改变画面合成。
3. 点击“处理已扫描片段”。AME 会把每个选中片段单独导出到系统临时目录，然后上传到 AI MediaKit 并执行 OCR。
4. 插件默认最多并行处理 2 个片段；可以在设置中调整为 1、2、3、5、10、15 或 20。插件先对可用预览并行上传和 OCR，再用第一段成功上传的视频作为示例预览。OCR 失败但上传成功的片段仍可按公共区域尝试擦除；上传失败的片段会跳过。
5. 在示例预览上拖动画框。拖框可移动，拖右下角控制点可缩放；可以新增或删除框，每段最多 20 个框。确认后，这组按画面宽高归一化的区域用于本批全部片段全程。
6. 插件显示本批估算费用并只确认一次，然后按设置的并行数提交擦除任务并下载结果。默认使用精细化模型 V5，单价估算按 ¥1/分钟，实际费用以 AI MediaKit 账户账单为准。火山账号另有任务并发配额；若遇到 429 限流，面板会提示降低并行数，受限片段不会自动重复提交。
7. 任务完成后，结果先下载到设置的本机目录。插件会读取处理结果尺寸，按原序列尺寸等比例恢复时间线画面大小，再核对活动序列、轨道、片段 ID、源路径和时间范围；只有身份仍匹配才替换视频画面。原音频轨道不改动，导出结果也保留临时输入中的音频。若云端把高分辨率输出降到 1080p，自动缩放只恢复时间线占比，不会恢复丢失的像素细节。

## 费用和文件保留

- 擦除任务提交前显示费用估算并需要再次确认。OCR 与云端任务是否另行计费，以火山引擎当前账户和产品计费规则为准。
- API MediaKit 本地上传文件的最长保留时间为 30 天；服务端任务完成后，插件会尽快下载结果。默认临时结果链接约 24 小时失效。
- 处理结果不会覆盖源媒体。若自动替换预检失败，输出文件仍留在结果目录，可手工导入。
- 临时预览素材保存在系统临时目录 `HardSubtitleRemover` 中。确认插件关闭且无需恢复任务后，可手工清理该目录。

## 当前边界与故障排查

- 片段按独立视频导出；带其他视频叠层、转场或复杂合成的区段会被跳过。静态框不跟随运动字幕，也不能逐帧变化。
- 目前处理片段最长受 AI MediaKit OCR 单文件 10 分钟限制；更长片段会由云端拒绝。建议先在 Premiere 中切成较短片段。
- API Key 错误：确认 Key 来自 AI MediaKit 控制台，而非火山方舟 API Key；删除后重新保存。
- AME 导出失败：确认 Media Encoder 已安装、可启动，且 `.epr` 路径存在并有读取权限。
- 上传失败：检查网络、视频文件是否在线、格式是否受支持，以及 AI MediaKit 上传地址是否过期。
- 云任务失败：面板会显示该片段错误；其他片段仍会继续处理。上传素材最长保留 30 天，结果 URL 通常有效 24 小时。
- 自动替换失败：若项目或时间线在云端处理期间被更改，插件会保留原片段并拒绝应用；已下载输出可在结果目录中找到。
- CEP 开发面板未出现：确认安装位置正确、Premiere 版本为 25.x，并仅在未签名开发版本场景配置 `CSXS.12\PlayerDebugMode=1` 后重启 Premiere。

## 移除

关闭 Premiere 后删除 `%APPDATA%\Adobe\CEP\extensions\com.codex.hardsubtitleremover`。若也要删除已保存的 Key，删除 `%APPDATA%\Codex\HardSubtitleRemover\api-key.dpapi`。
